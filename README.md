# Theme Studio — Support & Issue Tracker

This is the public issue tracker for **Theme Studio**, a desktop theming app for
Ubuntu / GNOME. The app's source code is private and lives elsewhere — this
repository exists only so customers can report bugs and request features.

## Report a bug or request a feature

1. Go to the [Issues](../../issues) tab.
2. Search first — someone may have already reported it.
3. Click **New issue** and pick a template:
   - **Bug report** — something is broken or behaving unexpectedly.
   - **Feature request** — an idea for something new.

## Before reporting a bug

Please have this information ready (the bug template asks for it):

- **Theme Studio version** — run `./theme-studio.sh --version`
- **Distro and version** — e.g. Ubuntu 26.04 LTS
- **GNOME Shell version** — run `gnome-shell --version`
- **What you did, what happened, what you expected**

Screenshots and terminal output are a big help.

## What NOT to post here

- No license keys, purchase details, or personal information.
- No re-uploads of the app's data pack or proprietary files.
- For purchase/billing questions, contact the seller directly instead.

## Code of conduct

Be respectful. Issues that are abusive, spam, or contain pirated content will
be closed and removed.
